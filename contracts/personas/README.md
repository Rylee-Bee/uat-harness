# Personas

One-line persona cards. A persona is a **who**, not a spec: one line, no biographies, no
demographics invented for flavour. If a line wouldn't change how you judge a screen, cut it.

**Card format (one line):**

```
**<name>** — <who they are in one clause>; <the one thing that must be obvious to them>.
```

Point the driver at a URL this persona would actually land on. Personas only frame *what you
look for* in the run; the driver's findings stay the same either way.

Files: one persona per `example-*.md` / `<slug>.md`, front-matter free, just the card.
