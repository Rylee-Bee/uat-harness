# Journey: Resume a task

**Persona:** [First-timer](../personas/example-first-timer.md)
**Job:** As someone who closed the tab mid-task, I want to get back where I was so that I don't redo work I already did.

1. Start at the top of the page with nothing in progress.
2. Open the thing I was working on and confirm it is still there, unchanged.
3. Reach the same screen I left, with my content intact.
